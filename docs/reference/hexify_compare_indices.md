# Compare two indices

Lexicographic comparison of two index strings.

## Usage

``` r
hexify_compare_indices(idx1, idx2)
```

## Arguments

- idx1:

  First index string

- idx2:

  Second index string

## Value

Integer: -1 if idx1 \< idx2, 0 if equal, 1 if idx1 \> idx2
