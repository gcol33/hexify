# Forward projection to specific face

Projects to a known face (skips face detection).

## Usage

``` r
hexify_forward_to_face(face, lon, lat)
```

## Arguments

- face:

  Face index (0-19)

- lon:

  Longitude in degrees

- lat:

  Latitude in degrees

## Value

Named numeric vector: c(icosa_triangle_x, icosa_triangle_y)
