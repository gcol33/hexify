# Convert area to effective resolution

Finds the effective resolution that gives approximately the target area.

## Usage

``` r
hexify_area_to_eff_res(area_km2)
```

## Arguments

- area_km2:

  Target area in km^2

## Value

Effective resolution (may be fractional)
