# Check if index type is valid for aperture

Check if index type is valid for aperture

## Usage

``` r
hexify_is_valid_index_type(
  aperture,
  index_type = c("auto", "z3", "z7", "zorder")
)
```

## Arguments

- aperture:

  Aperture (3, 4, or 7)

- index_type:

  Index type to check

## Value

Logical: TRUE if valid combination
