# Print resolution comparison table

**\[deprecated\]**

Use `hexify_compare_resolutions(print = TRUE)` instead.

## Usage

``` r
hexify_print_resolutions(aperture = 3, res_range = 0:10)
```

## Arguments

- aperture:

  Grid aperture (3, 4, or 7)

- res_range:

  Range of resolutions to display

## Value

Invisibly returns the comparison data frame
